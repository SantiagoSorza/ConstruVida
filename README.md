# ConstruVida

Plataforma de Hosting: GitHub Pages
URL del sitio en producción:
	https://santiagosorza.github.io/ConstruVida/

## Development server

Pasos específicos:
Desarrollo local: 
        npm i para instalar los paquetes de angular
        ng serve para pruebas
Build de producción: 
        ng build –configuration=production
Publicacion automatica: 
        Github Actions despliega automática al hacer push a main
